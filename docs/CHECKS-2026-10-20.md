# Исправление проверок · 20 октября 2026

## Причины

В `6fb226b` GitHub Checks останавливался на форматировании двух JSON-отчётов CPU, до запуска тестов. Отдельный локальный прогон текущей игры давал 280 успешных и 27 неуспешных проверок.

Большинство падений вызваны сменой пользовательского стандарта: высоты контакта, длина рук, темп L2, арена, музыка, дым и длительность сопровождения изменились, а сценарии продолжали ожидать прежние значения. Четыре сценария переключения начинали бег из точки, из которой текущий принимающий уже не успевал к узкой зоне нижнего приёма. Они теперь используют достижимую позицию; отдельные проверки недостижимого приёма сохранены.

Исторический набор частично наследовал современные настройки. Его профиль теперь берёт прежние значения из неизменяемого frozen v2, сохраняя актуальный движок и текущие контракты управления. Проверки импорта продолжают использовать современный валидатор. Архивные файлы не изменены.

Несколько старых сценариев подачи ожидали автоматического подброса при полной силе. Один из них бесконечно ждал выхода из стадии подачи. Сценарии теперь отпускают кнопку, ждут подброс и выполняют отдельное второе нажатие. Ожидание ограничено числом шагов, а задание CI ограничено 15 минутами.

## Исправление лаборатории

`simulateShot` без явной высоты выбирал 0.85 м для нижнего приёма и 2.05 м для атаки, вне разрешённых зон текущего профиля. Теперь высота примера ограничена настоящими границами контакта с учётом высоты игрока. Явно заданная высота сохраняется, чтобы лаборатория по-прежнему позволяла исследовать недоступные контакты. Дополнительная проверка покрывает произвольные зоны и прыжок; сравнение лаборатории с настоящим ручным контактом снова проходит.

## Испытания и анимации

Обновлены записанные последовательности реального ввода в `tests/fixtures/standard-challenges.json`. На текущих настройках они попадают во все десять целей и выполняют все десять низких спасений; сила ударов, цели и правила подсчёта не менялись.

Проверки проводки учитывают масштаб рук и погрешность дробных координат. Возврат верхнего приёма проверяется на 0.12 с, после обходящей лицо дуги; полный возврат и отсутствие задержки от пружины продолжают проверяться при 30/60/120 FPS.

В Linux CI дополнительно выявлено различие окончаний строк при Git checkout: исходные SHA-256 были записаны для Windows-файлов с CRLF и смешанными окончаниями. Исходный манифест и архив сохранены. Добавлен отдельный LF-манифест, созданный только после проверки всех 116 исходных хешей. Проверка допускает различие CRLF/LF для UTF-8 текста, сохраняя BOM и остальные байты; бинарные файлы проверяются точно. Отдельный регрессионный тест подтверждает оба окончания строк и отказ при изменении текста или PNG. С ним текущий набор содержит 309 проверок.

Проверки не отключались. Игровые настройки, физика матчей и поведение управления сохранены.
