# Duper Volleyball · Клуб

Пиксельный волейбол 3 на 3 с ручными ударами, физическим полетом мяча и игрой с клавиатуры или геймпада.

## Запуск

Node.js 20+: `npm ci`, затем `npm start` и [открыть игру](http://127.0.0.1:4173/). В Windows `PLAY.cmd` запускает сервер и открывает браузер после его готовности. `PLAY-DYNAMIC.cmd` — совместимый вариант того же запуска. Через `file://` игра не работает.

Текущая игра — корневые `index.html` и `src/`. Старые адреса `/versions/dynamic-v3/...` перенаправляются на нее.

## Игра

- **Кубок мира:** семь этапов, матчи до 7 очков, финал до 11. Этап и выигранные кубки сохраняются.
- **На двоих:** два геймпада играют слева против CPU. Сначала P1 управляет задней парой, P2 — передним; роли меняются после нашего выигранного розыгрыша. Подает владелец задней пары.
- **Против:** два геймпада управляют разными командами.
- **Испытания:** «Снайпер», «Мастер подачи», «Последний шанс» — по десять мячей, серии, звезды и рекорды.
- **Обучение:** шесть интерактивных шагов на стартовом экране. Для свободной тренировки есть «Разминка» и непрерывный «ТЕСТ».

| Действие               | Клавиатура     | Геймпад PlayStation / Xbox      |
| ---------------------- | -------------- | ------------------------------- |
| Движение и направление | Стрелки        | Левый стик / крестовина         |
| Нижний прием           | S              | □ / X                           |
| Сейв одной рукой       | A              | L2 / LT + прием                 |
| Верхний пас            | W              | △ / Y                           |
| Атака                  | D              | ○ / B                           |
| Прыжок                 | Space или ↑    | ✕ / A                           |
| Блок                   | F              | R1 / RB                         |
| Мягче / мощнее         | Z / C          | L2 / LT, R2 / RT                |
| Выбор игрока           | Tab, 1 / 2 / 3 | L1 / LB                         |
| Бросок                 | Q / E          | Три быстрых нажатия направления |
| Пауза                  | Enter / Escape | Options / Menu                  |

Удержание набирает силу; отпускание разрешает контакт у мяча. Нижний прием всегда поднимает мяч, верхний и атака следуют направлению. L2 имеет приоритет над R2. Направление считывается при контакте. Правый стик отключен.

L1/Tab переключает на следующего доступного игрока, 1–3 выбирают конкретного. Ручной выбор сохраняется до следующего касания мяча. Автовыбор принимающего затем возобновляется. Переключение во время зарядки или ожидания уже отпущенного удара заблокировано. Прежний игрок возвращается на позицию либо останавливается в свободном месте перед партнёром; новый сразу подчиняется вводу. В кооперативе нельзя забрать игрока второго контроллера; в «ТЕСТ» переключение отключено.

В «Физике» есть отдельная помощь пасу без направления (стандарт 65%) и нейтральной атаке (стандарт 0%). Помощь поворачивает траекторию без добавления силы; явное направление имеет приоритет. Точный приём → верхний навес → чистый третий удар дают золотой визуальный бонус.

Эксперимент «Перенос скорости при приёме» включается отдельно и по умолчанию выключен. Нижний приём наследует часть скорости сближения, максимум +5 м/с; L2/Z гасит добавку на 85%. В лаборатории задаётся входящая скорость для сравнения. «ТЕСТ» оставляет одного игрока и автоматически запускает мячи из случайных мест с разной силой.

Движение имеет короткий разгон и торможение, корпус и голова догоняют ноги. Резкий разворот сопровождается пылью и коротким звуком; приземление — мягким приседанием. Три точных касания складываются в восходящую мелодию. L3 больше не перезапускает эпизод; кнопка «Ещё попытка» остаётся в интерфейсе.

Перед подачей мяч лежит на ладони перед корпусом. Отпускание кнопки запускает короткий подъём руки и подброс; второе нажатие по-прежнему выполняет удар. Идеальный момент удара сохранён. Лаборатория подач показывает то же движение, что и матч.

Полноэкранный режим увеличивает реальное разрешение игрового холста с учётом плотности экрана, сохраняя пропорции 16:9. В «Физике → Эксперимент: третий удар» ползунок замедления задаёт плавное снижение темпа до 45% перед третьим касанием в прыжке рядом с мячом; стандарт — 0, выключено. Это общий темп симуляции, без изменения гравитации и скоростей мяча.

Подача требует двух нажатий: заряд → отпускание и подброс → новое нажатие у мигающего мяча. Полный заряд запускает подброс, а не готовый удар.

## Настройки

Стандарт — [профиль пользователя от 18 октября 2026](config/standard.json): темп 1×, скорость мяча 1.2×, гравитация 10.1 м/с², заряд 0.3 с, допуск отпускания 0.2 с. Новая установка и сброс используют его; сохраненные личные настройки продолжают действовать.

Лаборатория ударов использует ту же ручную модель, что матч, включая мягкий и мощный модификаторы. Подачи настраиваются отдельно. В графике можно отключить огонь и живой фон. Настройки сохраняются в браузере и JSON версии 4; файлы версий 2 и 3 читаются.

Рекорды разделены по физическим профилям. Смена графики или музыки не меняет категорию. При изменении физики в ходе попытки результат показывается без обновления рекорда. Прежние рекорды без профиля сохраняются отдельно. Параметры разрешено менять во время соревнований.

## Проверки и разработка

`npm run check` проверяет форматирование, текущую игру, совместимость, Classic и контрольные суммы архива. `npm run test:dynamic` сохранен как псевдоним `npm test`.

Для браузерных проверок: `npx playwright install chromium`, затем `npm run check:all`. CI запускает их автоматически. `npm run benchmark` записывает измерения времени симуляции и отрисовки в `.cache/benchmark.json`. Для диагностики контактов открыть `/?debug=1`.
