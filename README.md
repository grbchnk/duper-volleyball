# Duper Volleyball · Клуб

Пиксельный волейбол 3 на 3 с ручными ударами, физическим полетом мяча и игрой с клавиатуры или геймпада.

## Запуск

Node.js 20+: `npm ci`, затем `npm start` и [открыть игру](http://127.0.0.1:4173/). В Windows `PLAY.cmd` запускает сервер и открывает браузер после его готовности. `PLAY-DYNAMIC.cmd` — совместимый вариант того же запуска. Через `file://` игра не работает.

Текущая игра — корневые `index.html` и `src/`. Старые адреса `/versions/dynamic-v3/...` перенаправляются на нее.

## Игра

- **Кубок мира:** семь этапов с разными фонами и сложностью 0 → 20 → 40 → 60 → 80 → 92 → 100, матчи до 7 очков, финал до 11. Новый этап всегда задаёт свою арену и силу соперника, даже если настройки менялись в предыдущем матче. Этап и выигранные кубки сохраняются.
- **На двоих:** два геймпада играют слева против CPU. Сначала P1 управляет задней парой, P2 — передним; роли меняются после нашего выигранного розыгрыша. Подает владелец задней пары.
- **Против:** два геймпада управляют разными командами.
- **Испытания:** «Снайпер», «Мастер подачи», «Последний шанс» — по десять мячей, серии, звезды и рекорды.
- **Обучение:** шесть интерактивных шагов на стартовом экране. Для свободной тренировки есть «Разминка» и непрерывный «ТЕСТ».

| Действие                  | Клавиатура     | Геймпад PlayStation / Xbox      |
| ------------------------- | -------------- | ------------------------------- |
| Движение и направление    | Стрелки        | Левый стик / крестовина         |
| Нижний прием              | S              | □ / X                           |
| Мягкий нижний одной рукой | Z + S          | L2 / LT + приём / пас           |
| Верхний пас               | W              | △ / Y                           |
| Атака                     | D              | ○ / B                           |
| Прыжок                    | Space или ↑    | ✕ / A                           |
| Блок                      | F              | R1 / RB                         |
| Мягче / мощнее            | Z / C          | L2 / LT, R2 / RT                |
| Выбор игрока              | Tab, 1 / 2 / 3 | L1 / LB                         |
| Бросок                    | Q / E          | Три быстрых нажатия направления |
| Пауза                     | Enter / Escape | Options / Menu                  |

Удержание набирает силу; отпускание разрешает контакт у мяча. Нижний прием всегда поднимает мяч, верхний и атака следуют направлению. L2 имеет приоритет над R2. Направление считывается при контакте. Правый стик отключен.

Нижний приём использует угол выбранного профиля и силу заряда; входящая скорость не добавляет энергии. Нижний и верхний пас используют общую помощь направлению: первое касание предпочитает доступного связующего, второе — атакующего у сетки, третье — перевод на площадку соперника. Помощь поворачивает траекторию без добавления силы. Явное направление имеет приоритет и допускает коррекцию не более 12°; без направления — до 75°. Подробности — [помощь пасам и доигровка у сетки](docs/PASS-INTENT-2026-10-20.md).

В «Приёмы и подачи» каждый приём имеет независимые профили без модификатора, L2 и R2: скорость, углы, вращение, темп полёта и загиб атаки. L2 + R2 использует профиль L2. Настройки действуют в игре, сохраняются и сразу отражаются в лаборатории.

Удержание прыжка и его шкала убраны. Длина нажатия не меняет прыжок. Обычная пауза на вершине и дополнительное зависание при подготовке удара у мяча сохранены.

Ложные прыжки и заранее записанные комбинации убраны. L2 + верхний пас — аккуратный навес двумя руками; нижний мягкий приём остаётся одноручным. R2-атака имеет отдельный выраженный замах.

L1/Tab переключает на следующего доступного игрока, 1–3 выбирают конкретного. Ручной выбор сохраняется до следующего касания мяча. При входящем мяче движение сохраняет выбранного игрока, пока он ещё успевает к приёму; если он уже не успевает, управление может перейти доступному партнёру. Прыжок и удержание кнопки приёма сами по себе не блокируют покадровый автовыбор; подготовка удара переходит выбранному игроку. Паузы после ввода нет. Одновременное нажатие переключения и удара сначала выбирает игрока, затем начинает подготовку; уже начатая зарядка и ожидание отпущенного удара блокируют ручное переключение. Бросок сразу передаёт управление следующему доступному игроку, кроме случая закреплённого ручного выбора. После удара соперника через сетку принимающий может выбираться заранее. Прежний игрок возвращается на позицию через обычную логику движения. В кооперативе нельзя забрать игрока второго контроллера. В «ТЕСТ» переключение отключено.

При сильном входящем мяче прогноз учитывает точку снижения до высоты приёма и возможность каждого игрока успеть к мячу. Управление передаётся партнёру дальше по траектории, если тот заметно ближе к точке приёма, мяч уже прошёл текущего игрока или текущий игрок не успевает. Во время ручного движения доступный текущему игроку мяч остаётся за ним, даже если партнёр ближе к точке приёма. Если текущий игрок не успевает, автовыбор может передать управление партнёру; подготовленный удар следует за выбранным игроком. Явный ручной выбор сохраняет приоритет до следующего касания; в кооперативе сохраняется принадлежность игроков контроллерам.

После успешного паса своему партнёру принимающий выбирается обычным автовыбором, как в архиве: движение и прыжок его не блокируют, но ещё активная зарядка или ожидание удара задерживают выбор в одиночном управлении. Удар на сторону соперника сохраняет выбранного игрока.

Удар по голове с падением и звёздочками возможен только у неподготовленного игрока. Любая нажатая кнопка приёма или удара, активная зарядка и ожидание уже отпущенного удара защищают соответствующего игрока. Защита не заменяет правильный контакт с мячом и не распространяется на партнёров.

После пропущенного блока, когда входящий мяч уже позади блокирующего, вне досягаемости блока и летит в глубину площадки, управление сразу передаётся доступному принимающему. Блокирующий завершает прыжок самостоятельно. Для этой передачи снимается фиксация ручного выбора; удержание движения или блока и пауза после ввода её не задерживают. Подготовленный удар сохраняет приоритет. В кооперативе передача возможна только между игроками своего контроллера.

В «Физике» есть отдельная помощь направлению при пасе (стандарт 65%) и нейтральной атаке (стандарт 0%). Общий параметр помощи пасам также доступен у нижнего и верхнего паса в «Приёмы и подачи»; лаборатория позволяет выбрать номер касания и сравнить исходную и скорректированную дуги. Точный приём → верхний навес → чистый третий удар дают золотой визуальный бонус.

Эксперимент «Перенос скорости при приёме» включается отдельно и по умолчанию выключен. Нижний приём наследует часть скорости сближения, максимум +5 м/с; L2/Z гасит добавку на 85%. В лаборатории задаётся входящая скорость для сравнения. «ТЕСТ» оставляет одного игрока и автоматически запускает мячи из случайных мест с разной силой.

Движение имеет короткий разгон и торможение, корпус и голова догоняют ноги. Резкий разворот сопровождается пылью и коротким звуком; приземление — мягким приседанием. Три точных касания складываются в восходящую мелодию. L3 больше не перезапускает эпизод; кнопка «Ещё попытка» остаётся в интерфейсе.

Мяч сплющивается при контакте с руками и полом в зависимости от входящей скорости. Сжатие направлено вдоль прилёта, на полу — по вертикали; поперечное расширение сохраняет площадь. Максимальное сжатие удерживается 40 мс, чтобы удар читался на обычном размере мяча. Затем идут плавное восстановление и небольшое пружинящее растяжение; полное восстановление занимает 0.28 секунды. Деформация меняет только изображение мяча.

При вылете за верхнюю границу поля и возвращении мяч пробивает условный потолок: падают обломки и пыль, слышен треск. За границей мяч, его след и прогноз скрыты; тень плавно исчезает с высотой. Эффект не меняет физику. [Посмотреть повторяющийся пример](ceiling-preview.html) можно и на телефоне; звук включается кнопкой.

Перед подачей мяч лежит на ладони перед корпусом. Отпускание кнопки запускает короткий подъём руки и подброс. Единственная подсказка на поле — компактное тонкое кольцо вокруг мяча, без обводки, текста и шкалы. При подготовке оно постепенно набирает толщину, затем резко ускоряет сжатие и снова становится тоньше. До реального окна контакта мяча с кистью кольцо остаётся золотистым; зелёный цвет, минимальный радиус и короткий звук появляются при открытии точного удара. У края окна зелёный сигнал гаснет с небольшим запасом на следующий кадр ввода. Второе нажатие выполняется сразу, без запоминания и ожидания. Лаборатория подач показывает то же движение, что и матч.

В идеальной зоне подача сохраняет выбранные параметры. При раннем или позднем нажатии качество зависит от времени и расстояния до кисти: от почти полного удара до скользящего касания и полного промаха. Слабое касание постепенно приближается к свободному полёту подброшенного мяча. В «Приёмы и подачи → Подача» регулируются идеальное и допустимое окна, допуск кисти и мягкость ошибки; шкала тайминга показывает качество касания в процентах.

Полноэкранный режим увеличивает реальное разрешение игрового холста с учётом плотности экрана, сохраняя пропорции 16:9. Эксперименты третьего удара и переноса входящей энергии удалены из текущей игры.

Подача требует двух нажатий: заряд → отпускание и подброс → новое нажатие при схождении зелёного круга к мячу. Полный заряд сохраняется до отпускания кнопки. Без второго нажатия мяч упадёт. Ручное движение подающего заблокировано от подготовки до удара; направление подачи по-прежнему задаётся стиком или стрелками. Разбег и прыжок подачи выполняются своей анимацией. После удара движение снова доступно.

После промаха на подаче мяч падает с реальной скоростью подброса и отскакивает от пола. Сложность 0 — медленный новичок с поздней реакцией и неточной позицией: он может пропустить подброс или подать слишком слабо. С ростом сложности эти ошибки плавно исчезают. На 100 бот реагирует быстро, использует полную скорость игроков, точно исполняет выбранные удары и подбирает корректную подачу в рамках общей физики.

## Настройки

Графическая ветка `codex/sunset-street-graphics`: городская площадка на закате, процедурные слои Canvas, зрители со слежением за мячом и реакцией на очки. Площадка и ближние здания неподвижны; дальний город и отдельный передний план слегка смещаются за мячом. Тени строятся из текущего силуэта игрока с руками. Игроки стоят в три четверти: дальняя рука за корпусом, ближняя перед ним. Бег состоит из 12 кадров, остальные действия сохраняют общий риг и контакты. Подробности и воспроизведение визуальной проверки — [графика](docs/GRAPHICS-2026-10-19.md).

Стандарт — [профиль пользователя от 18 октября 2026](config/standard.json): темп 1×, скорость мяча 1.2×, гравитация 10.1 м/с², заряд 0.3 с, допуск отпускания 0.2 с. Новая установка и сброс используют его; сохраненные личные настройки продолжают действовать.

Настройки, внешность и лаборатории разделены общей навигацией с постоянными размерами окна. Каждый параметр редактируется в одном разделе. «Приёмы и подачи» объединяет единственный редактор параметров с живым предпросмотром. Настройки матча и условия примера подписаны отдельно; на широком экране ползунки и траектория стоят рядом, на узком — в двух областях одного окна. Внешность включает галерею голов и причёсок, а также независимую длину рук 70–130%; косметика рук сохраняет физическую досягаемость. Отдельный A убран: мягкий приём — Z/L2 + приём, мягкая подача-подсечка — Z/L2 + S/□. Сохранения — JSON версии 5, старые версии 2–4 мигрируют без возвращения отключённых функций.

Рекорды разделены по физическим профилям. Смена графики или музыки не меняет категорию. При изменении физики в ходе попытки результат показывается без обновления рекорда. Прежние рекорды без профиля сохраняются отдельно. Параметры разрешено менять во время соревнований.

## Проверки и разработка

`npm run check` проверяет форматирование, текущую игру, совместимость, Classic и контрольные суммы архива. `npm run test:dynamic` сохранен как псевдоним `npm test`.

[Причины и исправления прежних сбоев проверок](docs/CHECKS-2026-10-20.md): сценарии согласованы с текущим стандартом, исторический профиль закреплён, ожидание подачи ограничено.

Для браузерных проверок: `npx playwright install chromium`, затем `npm run check:all`. CI запускает их автоматически. `npm run benchmark` записывает измерения времени симуляции и отрисовки в `.cache/benchmark.json`. Для диагностики контактов открыть `/?debug=1`.

[Архитектура и команды разработки](docs/DEVELOPMENT.md) · [выполненные исправления](docs/REFACTOR-2026-10-18.md) · [аудит до исправлений](docs/PROJECT-AUDIT-2026-10-18.md) · [исторические заметки](docs/history/).

Проверка настроек и новые лаборатории: [аудит от 20 октября](docs/SETTINGS-2026-10-20.md). В разделе «Блок · зона и время» видны рабочее окно и зона отбития; для верхнего паса лаборатория сравнивает исходную и скорректированную дуги. После отпускания паса скорость бега плавно восстанавливается за допуск контакта.
