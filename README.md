# Super Volley Club

Пиксельный волейбол 3 на 3 в браузере. Три касания. Один мяч. План появится по ходу.

Ручные приёмы, заряд силы, физический полёт мяча и настраиваемые анимации. JavaScript ES Modules и Canvas 2D, без сборки и внешних игровых ресурсов. Для самой игры npm-зависимости не нужны.

## Запуск

Нужен Node.js 20 или новее.

```sh
npm start
```

Откройте <http://127.0.0.1:4173/>. В Windows можно запустить `PLAY.cmd`; если PowerShell блокирует npm, используйте `npm.cmd start`. Сервер слушает только локальный адрес. Другой порт: переменная окружения `PORT`. Через `file://` модули не загрузятся.

## Управление

| Клавиши       | Действие                                                   |
| ------------- | ---------------------------------------------------------- |
| ← / →         | Бег и направление контакта                                 |
| A / W / D     | Приём снизу / верхний пас / удар                           |
| Shift + ↑ / ↓ | Выше / настильнее во время заряда                          |
| ↑ / Space     | Вертикальный прыжок                                        |
| ↓ + ← / →     | Бросок с одним приёмом низкого мяча; A не требуется        |
| S             | Один блокирующий за новое нажатие                          |
| 1 / 2 / 3     | Задний / связующий / нападающий; E также выбирает третьего |
| Tab           | Следующий игрок                                            |
| Enter / Esc   | Пауза                                                      |
| R             | Следующий мяч в разминке или тестовом режиме               |

**Зажмите A/W/D, задайте направление и отпустите у мяча.** Если мяч коснётся подготовленных кистей при удержании, контакт произойдёт с накопленной силой. Одно нажатие даёт один контакт. Для следующего отпустите кнопку и нажмите снова.

**Подача требует двух нажатий:** зажать A/W/D → отпустить для подброса → нажать ещё раз для удара. Начните с 45–55% силы. A — снизу, W — сверху, D — с разбега и прыжка. Без второго нажатия мяч падает: гравитация не берёт выходных.

Поддерживается DualSense со стандартной браузерной раскладкой: левый стик — бег, ✕ — прыжок и старт, □/△/○ — приём/пас/удар, R1 — блок, L1 — смена игрока, L2 + ↑/↓ — угол удара, Options — пауза. Клавиатура работает одновременно; привязки используют физические коды клавиш и поддерживают русскую раскладку.

Полная инструкция открывается кнопкой «Методичка»; [guide.html](guide.html) поддерживает печать. [Текст инструкции](src/guide.js) общий для обеих страниц.

## Режимы и настройки

- **Матч:** игрок против компьютера. Три выигранных сета; по умолчанию до 15 очков, с преимуществом в два и потолком 17. Очки на своей подаче, в пятом сете — за каждый розыгрыш. Блок не расходует касание.
- **Разминка:** повторяемые упражнения на приём, пас, блок, подачу, броски и атаку у сетки.
- **ТЕСТ:** непрерывная подача тренировочных мячей без счёта и сброса позиций.
- **Смотреть:** обеими командами управляет компьютер.

Лаборатория регулирует физику, скорость, тайминги и анимации. Настройки сохраняются в браузере; доступны импорт и экспорт JSON. Прогноз показывает полёт мяча и возможный удар, а помощь пасу слегка корректирует импульс к партнёру.

Просмотр анимаций доступен по кнопке или через `/?view=arms`: выбор движения, силы, скина, замедление и стоп-кадр. Скин меняет только внешность.

Команды различаются цветами. Нет сетевой игры и сенсорного управления. Для игры нужна клавиатура или совместимый геймпад и современный настольный браузер с Canvas 2D, ES Modules и Web Audio.

## Разработка

```sh
npm ci
npm run check
```

`check` проверяет форматирование и запускает тесты текущей и классической версий. `npm test` — только текущие игровые тесты; `npm run format` — форматирование. Prettier используется только при разработке. GitHub Actions выполняет проверки на Node.js 22 и 24.

| Путь                                                     | Содержимое                                         |
| -------------------------------------------------------- | -------------------------------------------------- |
| `src/engine.js`, `src/rules.js`                          | Матч, фазы розыгрыша, счёт и компьютерный соперник |
| `src/physics.js`, `src/moves.js`, `src/held-contact.js`  | Полёт мяча, удары и контакты рук                   |
| `src/renderer.js`, `src/sprites.js`, `src/arm-motion.js` | Отрисовка и анимации                               |
| `src/main.js`, `src/input.js`, `src/audio.js`            | Интерфейс, ввод и звук                             |
| `tests/`                                                 | Автоматические проверки механик                    |
| `versions/classic-v1/`                                   | Самостоятельный архив первой версии                |

[Архитектура и развитие](docs/DEVELOPMENT.md). [Исследование классической версии](docs/REFERENCE.md).

Архив первой версии доступен по ссылке «Версия 01» в игре. Его можно запустить отдельно из `versions/classic-v1/` командой `npm start`. При этом порт 4173 должен быть свободен. Архив исключён из форматирования, чтобы сохранить исходный вариант.

## Размещение

Это статическая игра: достаточно раздать `index.html`, `guide.html`, `style.css`, `src/` и `versions/classic-v1/` через обычный статический хостинг. Сборка не требуется, ссылки относительные и поддерживают размещение в подпапке. `server.mjs` предназначен для локальной разработки.
