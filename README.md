# Super Volley Club · версия 02

Милая пиксельная 2D-игра с ручными касаниями, зарядом силы и физическим полётом мяча. Исходники открыты для редактирования: JavaScript ES Modules + Canvas 2D, без npm-зависимостей, ROM и внешних графических файлов. Это новое направление проекта с самостоятельным управлением, а не точная копия физики Sega.

## Запуск

Нужен Node.js 20+. Дважды щёлкните `PLAY.cmd` или выполните:

```powershell
npm.cmd start
```

Откройте [игру](http://127.0.0.1:4173/). Сервер доступен только на этом компьютере. Если он уже работает, второй запуск не нужен. Через `file://` ES-модули не работают.

## Сначала прочитайте методичку

[Полная методичка](http://127.0.0.1:4173/guide.html) также доступна в игре кнопкой «Методичка». Её можно распечатать или сохранить в PDF средствами браузера. Исходник текста: `src/guide.js`, страница: `guide.html`.

| Клавиши | Действие |
|---|---|
| ← / → | Бег и направление паса, в том числе во время заряда |
| A | Приём снизу предплечьями |
| W | Верхний пас, навес |
| D | Направленный удар; в прыжке — более плоская атака |
| Shift + ↑ / ↓ | Во время заряда: выше / настильнее |
| ↑ | Вертикальный прыжок |
| ↓ + ← / → | Нырок с падением на живот; контакт отдельно через A |
| S | Один свободный игрок у сетки прыгает в блок; следующее новое нажатие — следующий |
| 1 / 2 / 3 | Задний / связующий / нападающий у сетки (E также выбирает третьего) |
| Tab | Следующий игрок в розыгрыше |
| Enter / Esc | Пауза |
| R | Повторить мяч в разминке |

**Зажать → направить → отпустить возле мяча.** При удержании мяч, коснувшийся подготовленных кистей, отбивается с накопленной силой. Одно нажатие даёт один контакт; для следующего нужно отпустить кнопку и нажать снова. На подаче отпускание подбрасывает мяч, второе нажатие выполняет удар. Одно отпускание разрешает только один контакт в коротком окне; приём, пас связующего и атака требуют отдельных действий. Направление без модификатора — к сетке. Работает русская раскладка, цифровой блок не нужен.

Для DualSense в браузере со стандартной раскладкой: ✕ начинает матч и прыгает, левый стик — бег, крестовина — прыжок/нырок и направление, L2 + ↑/↓ — высота удара, □ — приём снизу, △ — верхний пас, ○ — удар, R1 — блок, L1 — смена игрока, Options — пауза. Удерживайте □/△/○ для заряда и отпускайте у мяча. Клавиатура продолжает работать одновременно.

Удержание ограничено: по умолчанию после 0.56 игровой секунды замах отменяется. Допуск после отпускания — 0.06 с, настраивается вплоть до нуля. Скорость бега при замахе — 65%, тоже настраивается. Время до максимальной силы сокращено вдвое (примерно 0.55 с при темпе 0.70×), диапазон силы сохранён. Во время подготовки можно бежать. Руки сразу занимают позу выбранного приёма; касание отмечается цветным импульсом, подписью и отдельным звуком. Прыжок быстрее, с замедлением подъёма, кратким зависанием и ускорением падения.

«Прогноз полёта и удара»: светлый пунктир — текущий полёт; цветной — удар сейчас, только когда мяч доступен рукам. На подаче используется будущая точка выпуска. Линии учитывают сетку, но не будущие действия игроков.

На подаче A — высокая одной рукой снизу, W — силовая одной рукой сверху, D — с разбега и прыжка. Зажмите для выбора силы и направления (руки остаются в стойке), отпустите для подброса, затем нажмите A/W/D ещё раз. Мигание — идеальное время; ранний или поздний удар слабее. Без второго нажатия мяч падает. Начните с 45–55% силы без Shift + ↑/↓.

## Хлёсткие руки и настройка

В игре используется один стиль — «Хлёсткие». Сила меняет подготовку и проводку; при верхнем пасе ладони образуют чашечку, после контакта кисти и локти вместе возвращаются в обычное положение. Прежние стили удалены из текущей версии. Настройки из старых JSON автоматически используют «Хлёсткие», сохраняя физику.

[Просмотр анимаций](http://127.0.0.1:4173/?view=arms) позволяет выбрать приём, силу, замедление, стоп-кадр и момент внутри движения. «Повторить» запускает цикл сначала. Сила и время просмотра не влияют на матч; выбранный скин применяется и в игре. В лаборатории 29 ползунков плюс отдельный темп игры: размер, упругость, локти, скорость подготовки, влияние силы и взмах в прыжке остаются доступны. Настройки сохраняются в JSON.

Для атаки у сетки: **3 → ↑ → короткий заряд D → отпускание у мяча**. Прыжок начинается с небольшого приседания. Упражнение «Навес → атака у сетки» позволяет повторять эту комбинацию через R. Блок работает только возле вершины прыжка и один раз за прыжок; на краях рабочего окна он смягчает мяч. Все его основные параметры настраиваются.

## Что изменилось

- Три игрока с каждой стороны, вся площадка видна одновременно. Пастельный парк, собственные пиксельные персонажи, анимации бега, прыжка, трёх контактов, блока, нырка, падения и подъёма.
- Две тактические фазы: защита и атака. Обычные касания человеческой команды выполняются отпусканием A/W/D, а бросок ↓ включает один нижний приём; после паса меняется только выбранный игрок. Автоматического бега к мячу нет.
- Темп по умолчанию 0.70×, крупный мяч со следом, индикатор доступности контакта, полоса заряда и прогноз траектории во время прицеливания.
- Помощь пасам A/W слегка корректирует начальный импульс к партнёру в выбранном направлении. Грубую ошибку направления или силы не исправляет. Её можно отключить.
- Обычный прыжок фиксирует горизонтальную координату и у человека, и у CPU. Нырок имеет отдельное движение с направлением, заданным при отталкивании.
- S запускает одного блокирующего за новое нажатие; удержание не повторяется. CPU не блокирует каждую атаку. После контакта блока снова доступны три касания и приём снизу.
- Разминка: повторяемый приём, верхний пас, блок и страховка, подача. Счёт не меняется.
- Настраиваемая физика, локальное сохранение параметров, импорт/экспорт JSON версии 2. Настройки версии 01 хранятся отдельно.

## Правила и ограничения

Матч до трёх выигранных сетов, сет до 15 с разницей в два и потолком 17. По умолчанию очки только на своей подаче, пятый сет — каждый розыгрыш; в настройках можно выбрать каждый розыгрыш во всех сетах. Блок не расходует касание.

Это рабочая основа новой игры. Клубы пока различаются цветами, CPU использует упрощённые комбинации. Нет сетевой игры, редактора анимаций и полноценной системы модов. Параметры и тайминги новой версии подобраны для ручного управления; точность относительно оригинала не заявляется. Исследование оригинала относится к сохранённой версии 01: `docs/REFERENCE.md`.

## Пиксельные кадры, скины и бросок с приёмом

Три скина: «Клубный» и «Уличный» без ушек, «Лисёнок» с ушками. По умолчанию — «Клубный». Корпус стал на два пикселя уже. src/sprites.js содержит 15 последовательностей нарисованных кадров тела: стойку, бег, толчок, взлёт, вершину, падение, приземление, три приёма, блок, бросок, лежание, подъём и подачу. Руки «Хлёсткие» сохранены. Просмотр поддерживает скины, номер кадра, стоп-кадр и перемотку.

**↓ + → / ←** — спасательный бросок в выбранную сторону. Он сразу готовит предплечья для одного приёма низкого мяча; A нажимать не надо. Направление фиксируется, автонаведения нет. Без стрелки используется сторона взгляда. После промаха или касания игрок приземляется и поднимается; удержание ↓ не повторяет бросок. **↑ / Space** остаётся вертикальным прыжком для ручной атаки или блока. В разминке добавлены оба броска. Скорость, высота, время подъёма и сила приёма доступны в лаборатории.
