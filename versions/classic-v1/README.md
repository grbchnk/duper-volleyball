# Super Volleyball / Reborn

Редактируемый игровой прототип по мотивам **Super Volleyball для Sega Mega Drive / Genesis**. Создан с нуля на JavaScript ES Modules и Canvas 2D, без ROM, внешних ассетов, игровых библиотек и сетевых сервисов.

Это **не точная эмуляция и не готовый полный ремейк**. Основные действия и правила сверены с руководством Mega Drive; физические коэффициенты и тайминги пока подобраны, а не извлечены из оригинала. Подробности — [исследование оригинала](docs/REFERENCE.md).

## Запуск

Нужен Node.js 20 или новее. Никакие npm-пакеты устанавливать не нужно.

```powershell
npm.cmd start
```

Откройте http://127.0.0.1:4173. Или запустите **PLAY.cmd** двойным щелчком. Сервер доступен только на вашем компьютере. Закрытие окна сервера останавливает игру для новых загрузок. Если браузер открылся до запуска сервера, обновите страницу. Если сервер уже работает, просто откройте адрес; запускать второй экземпляр не нужно.

Не открывайте index.html через file://: ES-модулям нужен HTTP-сервер.

## Управление на ноутбуке

Используются физические коды клавиш, поэтому русская раскладка не мешает.

| Mega Drive | Клавиатура | Значение |
|---|---|---|
| D-pad | WASD или стрелки | Передвижение принимающего, выбор комбинации по стадии |
| A | J или Z | Подброс, подача, приём, удар |
| B | K или X | Двойной блок; изменение варианта паса |
| A+B | Space | Одновременное действие без трёх клавиш |
| Start | Enter / Esc | Пауза |
| C | Не назначена | Замены состава пока не реализованы |

Начните с **J**, отпустите и снова нажмите **J**, когда подброшенный мяч покраснеет. На приёме — **J**, затем автоматический пас и разбег, затем **J** при красном мяче у нападающего. **K** ставит двойной блок при атаке соперника. Помощь с перемещением включена по умолчанию; её можно отключить справа. Касания при приёме и атаке допускают удержание J; на подаче нужен второй отдельный нажим.

Встроенная кнопка **«Все комбинации»** содержит полную таблицу подач, быстрых и открытых атак, задержки, атаки из глубины, скидок и специальных ударов. **W/S выбирают комбинацию, а не движение в глубину площадки**. Лаборатория позволяет менять гравитацию, сопротивление, прыжок, движение, силу и темп; настройки сохраняются локально и экспортируются/импортируются как JSON.

## Что работает

- Четыре активные игровые роли на сторону, боковая камера с прокруткой и радаром.
- Четыре стандартные подачи с подбросом и окном тайминга.
- Приём → автоматический пас → разбег/прыжок → удар; обычная, быстрая, задержанная, открытая и задняя атаки.
- Скидка со второго касания, обманный и усиленный удары, высокая и пикирующая спецподачи (приближения).
- Двойной блок, отскок от сетки, аут, переход подачи, до трёх сетов; лимит 17 и rally scoring в пятом сете.
- Восемь оформлений национальных команд, компьютерный соперник, демонстрация, пауза, синтезированные звуки.
- Собственная пиксельная графика, независимая симуляция 120 Гц и настраиваемая физика.

## Что ещё не перенесено

Покадровые тайминги и все особенности оригинального AI, статистические различия сборных и игроков, редактор/замены состава, World League и пароли, локальная игра вдвоём, оригинальная музыка/графика, сбивание защитника силовым ударом. Четыре показанные роли не моделируют полный шестипозиционный состав из оригинального редактора. Команды сейчас отличаются оформлением; сложность влияет на время блока CPU. Заявления о точной физике до измерений были бы неверными.

## Как развивать

| Файл | Ответственность |
|---|---|
| `src/engine.js` | Состояния розыгрыша, роли, AI, контакты |
| `src/moves.js` | Каталог атак/подач и выбор комбинаций |
| `src/physics.js` | Полёт мяча, сопротивление, вращение, пересечение сетки, прогноз |
| `src/rules.js` | Очки, сеты, пятый сет, победа в матче |
| `src/config.js` | Начальные параметры, диапазоны, оформления команд |
| `src/renderer.js` | Камера, собственные спрайты, стадион, интерфейс матча |
| `src/main.js` | Ввод, интерфейс, фиксированный шаг, настройки и сохранение |
| `src/audio.js` | Звуки через Web Audio |

Добавление новой атаки: [руководство разработчика](docs/DEVELOPMENT.md). На существующем коде можно перейти на другой renderer/движок, сохранив независимые модули физики, правил и состояний.

## Проверка

```powershell
npm.cmd test
```

Тесты проверяют баллистику, сетку, границы, траектории, правила счёта, направления комбинаций, отдельное нажатие подачи, спецподачи, двойной блок, воспроизводимость и длинный матч CPU. UI проверяется в браузере; unit-тесты не доказывают сходство ощущений с оригинальной игрой.

## Старые файлы игры

В этой папке не было ROM или исходников. ROM сам по себе не превращается в редактируемый проект современного движка. Для более точного восстановления полезен отдельный разбор конкретной версии картриджа: запуск в эмуляторе, frame advance, журнал ввода, измерения движения и при необходимости дизассемблирование. Эти действия здесь не выполнялись. Исходники оригинала и код эмулятора не включены.
