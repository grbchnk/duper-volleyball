# Duper Volleyball

Пиксельный волейбол 3 на 3: ручные касания, физический полёт и лаборатории настройки.

## Запуск

Node.js 20+: `npm start`, затем http://127.0.0.1:4173/. В Windows доступен `PLAY.cmd` или `npm.cmd start`. Сборка не нужна, через file:// модули не работают.

## Актуальные правила и управление

Полная методичка открывается кнопкой «Методичка» или в `guide.html`; общий источник — `src/guide.js`.

| Управление        | Действие                                      |
| ----------------- | --------------------------------------------- |
| ← / →             | Бег и направление                             |
| S / A / W / D     | Снизу / сейв одной рукой / верхний пас / удар |
| ↑ или Пробел / ↓  | Прыжок / приседание                           |
| Shift + ↑ / ↓     | Направление выше / ниже без прыжка            |
| F                 | Блок в защите                                 |
| Q / E             | Рывок влево / вправо с одним приёмом          |
| Tab, 1 / 2 / 3    | Смена / выбор игрока                          |
| Enter, Escape / R | Пауза / повтор упражнения                     |

Геймпад: левый стик — бег, нажатие R3 — рывок в сторону наклона (нейтраль: вправо). A/✕ — снизу, X/□ — сейв, Y/△ — пас, B/○ — удар; LB/L1 — смена игрока, RB/R1 — блок. Правый стик выбирает тип приёма. В настройках есть режим приоритета правого стика: первый наклон фиксирует тип, дальнейший поворот задаёт направление до касания. Обычный режим использует только стрелки/левый стик для направления. Тройное нажатие стрелки оставлено дополнительным способом рывка.

Удержание готовит руки и набирает силу; мяч может коснуться подготовленных ладоней. Отпускание выполняет удар с настраиваемым временным допуском. Подача: заряд → отпускание/полный заряд → подброс → второе нажатие. Без второго нажатия удара нет.

Матч до трёх выигранных сетов; цель по умолчанию 15, разница в два, потолок 17. По умолчанию очки на своей подаче; пятый сет — каждый розыгрыш. До трёх командных касаний, без двух подряд одним игроком; блок не расходует обычное касание. Режим начисления и цель меняются в настройках.

## Лаборатории

- **Удары → Подачи:** цветная шкала результатов реальной симуляции, момент второго нажатия, стоп-кадр, траектория. Настраиваются идеальное/допустимое окна, сила неточного удара, подброс и досягаемость кисти.
- **Удары → Приёмы:** рамка высоты/дальности контакта и рабочие ладони. Допуски действуют также на удержание. Угол в воздухе работает выше 0.25 м; ручной угол с влиянием 100% заменяет профиль. Помощь может корректировать дугу.
- **Вращение:** положительное загибает вниз, отрицательное замедляет падение; сиреневая контрольная траектория рассчитана без вращения. Пунктир без помощи сравнивает именно помощь.
- **Физика → Приём одной рукой:** пределы угла руки A. 0° означает горизонтальную руку (90° к телу), отрицательный угол — ниже плеча. Изменяется и анимация, и рабочая ладонь.
- **Внешность и управление:** независимые скины/цвета команд; четыре скина мяча, визуальный размер (120% по умолчанию), огонь от скорости. Физический радиус мяча сохраняется. Порог огня — в лаборатории физики.

Страница помещается в высоту окна; настройки прокручиваются внутри боковой панели, лаборатории — внутри диалогов. Все настройки сохраняются в браузере и экспортируются в JSON версии 2. Старые файлы дополняются новыми значениями по умолчанию.

## Проверка

`npm test` — игровые регрессии, физика, управление, лаборатории и полный CPU-матч. `npm run test:classic` — архивная версия. `npm run format:check` — форматирование.

## Файлы

`src/engine.js` — матч и контакты; `input.js` — управление; `physics.js` — полёт; `moves.js` — импульсы; `shot-settings.js` и `serve-settings.js` — профили; `shot-lab.js` и `serve-lab.js` — лаборатории; `renderer.js`, `receive-pose.js` — отрисовка и ладони.

`versions/classic-v1/` — отдельный неизменённый архив. `docs/REFERENCE.md` — историческое исследование оригинала, не правила текущей игры. `docs/DEVELOPMENT.md` — технические заметки; старые заметки об отдельных обновлениях сохраняют исторический контекст.

## Переключение и бот

Автоматический выбор пересматривает достижимость входящего мяча каждый игровой шаг. Пока активный игрок успевает, выбор сохраняется; после потери возможности контакта выбирается доступный партнёр. Заряд сохраняется при передаче управления. Бот начинает подготовку за время нужного заряда до контакта и не пытается повторно принять свою уходящую подачу. Минимальное расстояние центра игрока от сетки увеличено до 0.65 м.

## Графика и общий JSON

«Графика» объединяет внешний вид команд, рисунок/размер мяча, огонь, единую пиксельную сетку, живой фон, параметры рук и анимации. Пять рисунков мяча, включая чистый без рисунка, используют общий рендерер в матче и лабораториях. По умолчанию используется прежнее сглаживание. В пиксельном режиме вся сцена выводится на общей сетке 2×2, края рук и текста имеют бинарную прозрачность. Размер мяча учитывается сеткой: верхняя лента даёт мягкий подскок, нижняя часть — отскок назад; сетка колеблется после контакта. Зрители следят за мячом и радуются очкам своей команды; фон заполняет поля вокруг площадки.

«Настройки / JSON» выгружает всю конфигурацию, включая профили подач/ударов, анимации, команды, управление, звук и отображение. Это не сохранение текущего матча или состояния просмотра лаборатории. Старые JSON версии 2 поддерживаются. Все диалоги закрываются кликом снаружи, Escape и закреплённым крестиком.
